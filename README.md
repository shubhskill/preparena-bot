# PrepArena Student Bot

Student-facing Telegram bot for PrepArena.

## Current scope
- Telegram-based permanent student identity
- Available Tests
- Open scheduled/live test details
- Join LIVE tests
- Send all questions with answer buttons
- MCQ answer saving
- Multiple Correct toggle/save behavior
- Numerical answer input
- My Results
- My Profile
- Support forwarding

Built with Python, Telegram Bot API, Supabase, GitHub and Railway.

## Railway variables
- BOT_TOKEN
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- SUPPORT_CHAT_ID (optional until support routing is configured)

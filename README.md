# PrepArena Student Bot — Contextual Menu Fix

This version makes the inline keyboard change with the current screen instead of showing the main four options everywhere.

Menu behavior:
- Main menu: Available Tests, My Results, My Profile, Support, Logout
- Available Tests: test list, Main Menu, Logout
- Test details: Join/Waiting, Back, Logout
- Results/Profile/Support: their own screen controls, Main Menu, Logout
- Question answer buttons remain question-specific and include Logout

Support recipients remain in `support_config.py`.
